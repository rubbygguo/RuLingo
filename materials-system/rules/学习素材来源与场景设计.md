# 学习素材来源与场景设计

这份文档记录当前阶段对英文学习素材体系的设计建议。它不是最终方案，而是一份可持续迭代的讨论底稿。

当前用户背景：

- 香港研究生在读
- 希望系统性提升英语，而不是只做零散练习
- 高频需求包括学术阅读、seminar 讨论、presentation、写作、求职准备、日常社交和真实生活沟通

核心判断：

素材库不应只是“英语资料收藏夹”，而应服务于真实任务训练。更合适的组织方式是：

```text
场景 -> 任务 -> 技能 -> 素材 -> 练习输出
```

例如：

```text
学术场景 -> seminar 发言 -> 听 + 说 -> 一段课堂讨论材料 -> 复述观点并提出回应
职业场景 -> networking -> 读 + 写 + 说 -> LinkedIn message 样例 -> 写一条邀约消息并口头模拟
生活场景 -> 看医生 -> 听 + 说 -> 医患对话 -> 描述症状并追问建议
```

## 1. 场景框架

当前建议先覆盖 4 类核心场景。

### 1.1 学术场景

这是当前阶段优先级最高的场景，因为它直接对应研究生生活。

可覆盖任务：

- 阅读论文 abstract、introduction、discussion
- 参加 seminar 讨论
- 向导师或同学解释自己的观点
- 做 presentation
- 写 academic email
- 写 essay、report、proposal 或 reflection
- 在 group project 中协作沟通

典型素材：

- 本专业论文片段
- 课堂阅读材料
- seminar discussion question
- presentation transcript
- academic phrase examples
- 导师邮件、课程通知、assignment brief

### 1.2 职业场景

这个场景服务于 internship、job application 和未来职场沟通。

可覆盖任务：

- 写 CV、cover letter
- 准备 interview answers
- 发 networking message
- 做 self-introduction
- 参加 workplace meeting
- 写 business email
- 在 LinkedIn 上介绍经历和项目

典型素材：

- job description
- LinkedIn profile / message 样例
- cover letter 样例
- interview question bank
- workplace meeting phrases
- business email 模板

### 1.3 社交生活场景

这个场景用于补足自然交流能力，尤其是“能看懂但说不自然”的部分。

可覆盖任务：

- small talk
- 和同学、室友、朋友聊天
- 租房、银行、看医生、办手续
- 参加校园活动
- 解释自己的专业、兴趣和日常安排
- 礼貌拒绝、提出请求、表达感谢或歉意

典型素材：

- 日常对话
- campus life conversation
- service encounter dialogue
- real-life message examples
- short social podcast / video clips

### 1.4 知识输入场景

这个场景用于扩大词汇、表达方式和背景知识，也可以作为泛听、泛读来源。

可覆盖任务：

- 听播客或讲座
- 阅读新闻、科普、评论文章
- 总结一个观点
- 表达同意、反对或延伸
- 把输入内容转化为口语或写作素材

典型素材：

- TED Talks
- BBC / NPR / The Conversation 文章
- 大学公开课片段
- 专业相关 podcast
- 科普类视频或文章

## 2. 听说读写的素材来源

### 2.1 听力素材

听力素材优先选择有 transcript、字幕或文本稿的内容。这样同一份材料可以同时支持听力、跟读、表达积累和复述练习。

适合来源：

- BBC Learning English：适合日常表达、新闻英语、发音和短音频。
- British Council LearnEnglish：有听力、口语、阅读、写作分类材料，也覆盖工作和朋友交流场景。
- VOA Learning English：语速较慢，适合精听、听写和跟读。
- TED Talks：适合中高级输入，很多演讲有 transcript，可用于观点总结和表达积累。
- 学校课程录音或公开课片段：适合训练真实学术听力。
- 专业相关 podcast：适合长期泛听和积累领域表达。

建议把听力分成两类：

```text
慢速可控输入：VOA、BBC Learning English、分级听力材料
真实语速输入：TED、NPR、课程讲座、专业 podcast、YouTube lecture
```

可转化练习：

- 听 1 遍抓主旨
- 听 2 遍补细节
- 精听 30-60 秒
- shadowing
- 30 秒英文 summary
- 提取 3-5 个可复用表达

### 2.2 口语素材

口语素材不只是音频，更重要的是可模仿、可替换、可迁移的表达模板。

适合来源：

- British Council 的 speaking / business communication 材料
- BBC Learning English 的 everyday English、pronunciation、短对话内容
- Coursera 或大学公开课中的 career English / academic speaking 内容
- 真实生活里的邮件、课堂讨论、同学聊天、学校行政沟通
- interview question、seminar question、presentation Q&A

口语练习建议分三层：

```text
模仿一句 -> 替换信息 -> 独立完成任务
```

例如：

```text
I see your point, but I’m wondering whether...
```

可以先模仿，再替换成本专业语境，最后用于 seminar response。

可转化练习：

- 跟读 5 句
- 改写成自己的语境
- 用 30-60 秒回答一个问题
- 录音并复盘卡顿点
- 准备 3 个 seminar 可用句型
- 模拟 interview 或 networking 对话

### 2.3 阅读素材

阅读材料应同时包含分级材料和真实材料。分级材料帮助稳定提升，真实材料帮助迁移到研究生生活。

适合来源：

- Cambridge English 学习活动：适合按技能和 CEFR 难度选择。
- British Council 阅读材料：适合 B1-C1 阶段练习。
- 本专业论文和课程阅读：适合学术阅读训练。
- The Conversation、BBC、NPR 等新闻或知识类文章：适合泛读和观点输入。
- assignment brief、course handbook、学校邮件：适合真实任务阅读。

阅读材料建议分三类：

```text
精读：短、难度略高、反复分析句子和表达
泛读：兴趣驱动，大量输入
专业阅读：与研究方向或课程任务直接相关
```

研究生阶段尤其应该加入“论文阅读英语”模块，训练：

- 识别 author stance
- 快速读 abstract
- 总结 research gap
- 提取 academic phrases
- 区分 claim、evidence、limitation
- 把论文表达转成 presentation 语言

### 2.4 写作素材

写作素材不应只收好文章，也应收结构、句型、语气、改写和错误样本。

适合来源：

- Purdue OWL：适合学术写作、研究生写作和引用规范。
- British Council 写作材料：适合不同文体的 model text。
- Cambridge Write & Improve：适合基础写作练习和反馈。
- 自己的真实写作任务：email、proposal、reflection、essay、report、paper draft、presentation script。
- 优质论文中的 abstract、introduction、discussion 片段。

写作素材可积累的内容：

- 好句型
- 段落结构
- 邮件模板
- 常见错误
- 同义改写
- 连接逻辑
- hedging 表达
- 语气强弱

示例：

```text
原始表达：This paper says...
升级表达：The paper argues that...
更学术表达：The authors contend that...
更谨慎表达：The findings suggest that...
```

可转化练习：

- 仿写一个段落
- 改写一句不自然表达
- 写一封真实邮件
- 写 150 字 reading response
- 把口语表达改成学术表达
- 把论文句子改成 presentation 语言

## 3. 素材筛选标准

每个素材进入系统前，建议至少满足 3 个条件：

```text
有文本或字幕
能对应真实任务
难度略高于当前水平
长度可控
语言质量可靠
可以产生输出
可重复练习
```

尤其要重视“可以产生输出”。

判断问题不是：

```text
这个素材能不能学？
```

而是：

```text
学完之后，我能用它做什么？
```

例如，一段 TED 演讲可以转化为：

- 30 秒口头 summary
- 5 个 academic / discussion phrases
- 1 段 agree / disagree response
- 1 篇 reflection
- 1 次 shadowing 练习

## 4. 当前素材配比假设

当前建议的初始配比是：

```text
40% 学术英语
25% 职业英语
20% 真实生活 / 社交英语
15% 兴趣输入
```

这只是阶段性假设，不是固定规则。后续可以根据实际使用情况调整，例如：

- 如果课程压力大，提高学术英语比例。
- 如果准备求职，提高职业英语比例。
- 如果发现社交表达明显卡顿，提高生活 / 社交英语比例。
- 如果学习疲劳，提高兴趣输入比例，用来维持长期动力。

听说读写也不需要平均分配。当前更建议优先：

```text
听力 + 口语输出 > 学术阅读 > 写作润色
```

原因是研究生生活中，很多高压场景发生在课堂讨论、presentation、office hour、interview 和日常沟通中，反应速度和自然表达会直接影响使用体验。

## 5. 素材进入系统后的处理流程

建议以后新增素材时，按下面流程处理：

1. 判断素材属于哪个场景：学术、职业、社交生活、知识输入，或多个场景。
2. 判断素材主要训练什么技能：听、说、读、写，或组合技能。
3. 记录来源、难度、主题、标签和适用任务。
4. 提取可复用表达。
5. 设计一个小输出任务。
6. 关联到学习计划、表达库、口语练习或写作练习。
7. 在复盘中记录这个素材是否值得重复使用。

对应数据思路：

```text
素材 Material
  -> 表达 Expressions
  -> 练习 Practice
  -> 输出 Output
  -> 复盘 Check-in
```

## 6. 后续待讨论问题

这份文档后续可以继续调整这些问题：

- 四类场景是否足够，是否需要单独加入“考试场景”？
- 素材配比是否应随学期阶段、求职阶段动态变化？
- 听说读写是否需要设定每周最低练习量？
- 是否要为素材增加 CEFR 难度或主观难度评分？
- 是否需要建立“素材质量评分”，淘汰低价值素材？
- 如何把真实课程材料纳入系统，同时避免整理成本过高？
- 是否要区分“泛输入素材”和“精练素材”？
- 是否要为每份素材强制生成一个输出任务？

## 7. 当前一句话原则

这个系统的素材来源可以很多，但组织方式应该始终围绕真实身份和真实任务：

```text
香港研究生
未来求职者
学术讨论参与者
日常英语使用者
```

目标不是越存越多，而是让每一份素材都能变成可练习、可复用、可迁移的英语能力。
