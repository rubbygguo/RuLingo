# 表达库：起步版

## 学术和课堂讨论

| 表达 | 意思 | 我的句子 |
|---|---|---|
| The author seems to argue that... | 作者似乎认为…… |  |
| I agree with this point to some extent because... | 我在某种程度上同意，因为…… |  |
| A possible limitation is... | 一个可能的局限是…… |  |
| Could we also consider this from the perspective of...? | 我们是否也可以从……角度考虑？ |  |
| Building on what you just said... | 接着你刚才说的…… |  |
| That relates to the issue of... | 这与……问题有关 |  |
